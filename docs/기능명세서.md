# 2. 시스템 개요

DW Data Validator는 Source Table과 Target Table의 데이터를 자동으로 비교하여 데이터 정합성을 검증하는 프로그램이다.

사용자는 Validation Config Excel 파일만 수정하면 다양한 테이블에 대해 동일한 검증을 수행할 수 있으며, 검증 결과는 Console, Excel Report 및 Validation History에 저장된다.



# 3. 시스템 구성

```
┌──────────────────────────────┐
│  Validation Config (Excel)   │
└──────────────┬───────────────┘
               │
               ▼
      Config 정보 읽기
 (Validation Name, Table 정보,
  Compare Column, PK 등)
               │
               ▼
      Source / Target 조회
        (PostgreSQL)
               │
               ▼
     Validation 수행
 ┌────────────────────────────┐
 │ • Count Validation         │
 │ • Sum Validation           │
 │ • Group By Validation      │
 │ • Row Compare Validation   │
 └─────────────┬──────────────┘
               │
               ▼
      Validation 결과 생성
               │
      ┌────────┴────────┐
      ▼                 ▼
 Excel Report      Validation History
   생성                 저장
      │                 │
      └────────┬────────┘
               ▼
          Validation 완료
```

# 7. Validator Module

## 개요

### 목적

Source Table과 Target Table 간 데이터 정합성을 검증하기 위한 핵심 모듈이다.

Validation Config에서 전달받은 검증 조건에 따라 아래 4가지 검증을 수행한다.

| Validation Type | 목적 |
| --- | --- |
| Count Validation | Source / Target 데이터 건수 비교 |
| Sum Validation | 지정 컬럼 합계 비교 |
| Group By Validation | 그룹별 집계 결과 비교 |
| Row Compare Validation | PK 기준 데이터 변경 여부 비교 |



## Validator Class

### 기능

Validation 유형별 검증 로직을 통합 관리한다.

### Method

| Method | 설명 |
| --- | --- |
| validate_count() | Source / Target Row Count 비교 |
| validate_sum() | 컬럼별 Sum 비교 |
| validate_groupby() | Group By 집계 결과 비교 |
| validate_rowcompare() | PK 기준 Row 비교 |



## 공통 Method

### _split_columns()

#### 목적

Config Excel에 저장된 문자열 형태의 Column 정보를 List 형태로 변환한다.

#### Input

| Parameter | Type |
| --- | --- |
| columns | String |

Example)

```
"sale_amt,qty"
```

#### Output

```
[
    "sale_amt",
    "qty"
]
```

#### 처리 로직

1. Column 문자열 Split 수행
2. Column별 공백 제거
3. List 형태 반환



# 7.1 Count Validation

## 목적

Source와 Target Table의 데이터 건수를 비교하여 데이터 적재 여부를 검증한다.



## Method

```
validate_count(
    source_df,
    target_df
)
```



## Input

| Parameter | Type |
| --- | --- |
| source_df | DataFrame |
| target_df | DataFrame |



## Output

```
{
    validation_type,
    source_count,
    target_count,
    result
}
```



## 처리 로직

1. Source 데이터 건수 조회
2. Target 데이터 건수 조회
3. Count 값 비교
4. Validation 결과 반환



# 7.2 Sum Validation

## 목적

Config에 지정된 비교 대상 컬럼의 합계를 비교하여 데이터 값의 정합성을 검증한다.



## Method

```
validate_sum(
    source_df,
    target_df,
    compare_columns
)
```



## Input

| Parameter | Type |
| --- | --- |
| source_df | DataFrame |
| target_df | DataFrame |
| compare_columns | String |



## Output

```
[
    {
        column,
        source_sum,
        target_sum,
        result
    }
]
```



## 처리 로직

1. 비교 대상 Column List 변환
2. Source Column별 Sum 계산
3. Target Column별 Sum 계산
4. Sum 결과 비교
5. Column별 Validation 결과 반환



# 7.3 GroupBy Validation

## 목적

Group By 기준으로 집계한 Source와 Target 데이터를 비교하여 그룹 단위 데이터 정합성을 검증한다.



## Method

```
validate_groupby(
    source_df,
    target_df,
    group_by_columns,
    compare_columns
)
```



## Input

| Parameter | Type |
| --- | --- |
| source_df | DataFrame |
| target_df | DataFrame |
| group_by_columns | String |
| compare_columns | String |



## Output

```
{
    validation_type,
    group_by_columns,
    compare_columns,
    result,
    difference_df
}
```



## 처리 로직

1. Group By Column List 변환
2. Source 데이터 Group By 수행
3. Target 데이터 Group By 수행
4. Compare Column 합계 계산
5. Group Key 기준 Source / Target Merge 수행
6. 집계 결과 비교
7. 차이가 발생한 Group 데이터 반환



# 7.4 Row Compare Validation

## 목적

Primary Key 기준으로 Source와 Target Row 데이터를 비교하여 데이터 변경 내역을 검증한다.

검증 대상:

- INSERT 데이터
- UPDATE 데이터
- DELETE 데이터



## Method

```
validate_rowcompare(
    source_df,
    target_df,
    pk_columns
)
```



## Input

| Parameter | Type |
| --- | --- |
| source_df | DataFrame |
| target_df | DataFrame |
| pk_columns | String |



## Output

```
{
    validation_type,
    result,
    pk_columns,
    compare_columns,
    insert_rows,
    delete_rows,
    update_rows
}
```



## 처리 로직

1. PK Column List 변환
2. PK 기준 Source / Target Index 생성
3. Source에는 없고 Target에 존재하는 데이터 추출 (INSERT)
4. Source에는 존재하고 Target에 없는 데이터 추출 (DELETE)
5. 동일 PK 데이터의 Column 값 비교 (UPDATE)
6. Validation 결과 반환



## Row Compare 결과 기준

| 조건 | 결과 |
| --- | --- |
| INSERT / UPDATE / DELETE 데이터 없음 | PASS |
| 변경 데이터 존재 | FAIL |

# 10. 데이터베이스 명세

## 10.1 ODS_SALES

**테이블명**

`valid.ods_sales`

**설명**

Source 시스템의 판매 데이터를 저장하는 테이블로 Validation의 기준(Source) 데이터로 사용한다.

| 컬럼명 | 타입 | PK | NOT NULL | 설명 |
| --- | --- | --- | --- | --- |
| sale_id | INTEGER | O | O | 판매번호 |
| sale_dt | DATE |  | O | 판매일자 |
| store_cd | VARCHAR(20) |  | O | 매장코드 |
| product_cd | VARCHAR(20) |  | O | 상품코드 |
| qty | INTEGER |  | O | 판매수량 |
| sale_amt | NUMERIC(10,2) |  | O | 판매금액 |



## 10.2 FACT_SALES

**테이블명**

`valid.fact_sales`

**설명**

DW 적재 결과를 저장하는 테이블로 Validation의 대상(Target) 데이터로 사용한다.

| 컬럼명 | 타입 | PK | NOT NULL | 설명 |
| --- | --- | --- | --- | --- |
| sale_id | INTEGER | O | O | 판매번호 |
| sale_dt | DATE |  | O | 판매일자 |
| store_cd | VARCHAR(20) |  | O | 매장코드 |
| product_cd | VARCHAR(20) |  | O | 상품코드 |
| qty | INTEGER |  | O | 판매수량 |
| sale_amt | NUMERIC(10,2) |  | O | 판매금액 |



## 10.3 VALIDATION_HISTORY

**테이블명**

`valid.validation_history`

**설명**

Validation 수행 결과를 저장하는 이력 테이블이다.

| 컬럼명 | 타입 | PK | NOT NULL | 설명 |
| --- | --- | --- | --- | --- |
| history_id | SERIAL | O | O | 이력번호 |
| validation_name | VARCHAR(100) |  | O | Validation 명 |
| count_result | VARCHAR(10) |  | O | Count Validation 결과 |
| sum_result | VARCHAR(10) |  | O | Sum Validation 결과 |
| groupby_result | VARCHAR(10) |  | O | Group By Validation 결과 |
| rowcompare_result | VARCHAR(10) |  | O | Row Compare Validation 결과 |
| run_dt | TIMESTAMP |  | O | Validation 수행 일시 |



### 테이블 관계

| Source Table | Target Table | Validation 대상 |
| --- | --- | --- |
| valid.ods_sales | valid.fact_sales | Count, Sum, Group By, Row Compare |
