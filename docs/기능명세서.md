# 2. 시스템 개요

DW Data Validator는 Source Table과 Target Table의 데이터를 자동으로 비교하여 데이터 정합성을 검증하는 프로그램이다.

사용자는 Validation Config Excel 파일만 수정하면 다양한 테이블에 대해 동일한 검증을 수행할 수 있으며, 검증 결과는 Console, Excel Report 및 Validation History에 저장된다.



# 3. 시스템 구성

```
┌──────────────────────────────┐
│  Validation Config (Excel)   │
└──────────────┬───────────────┘
               │
               ▼
      Config 정보 읽기
 (Validation Name, Table 정보,
  Compare Column, PK 등)
               │
               ▼
      Source / Target 조회
        (PostgreSQL)
               │
               ▼
     Validation 수행
 ┌────────────────────────────┐
 │ • Count Validation         │
 │ • Sum Validation           │
 │ • Group By Validation      │
 │ • Row Compare Validation   │
 └─────────────┬──────────────┘
               │
               ▼
      Validation 결과 생성
               │
      ┌────────┴────────┐
      ▼                 ▼
 Excel Report      Validation History
   생성                 저장
      │                 │
      └────────┬────────┘
               ▼
          Validation 완료
```

# 5. Validator Module

Source Table과 Target Table 간 데이터 정합성을 검증하는 핵심 모듈이다.

Validation Config에서 정의한 검증 조건에 따라 COUNT, SUM, GROUP BY, ROW COMPARE 검증을 수행한다.

### 주요 검증 기능

| Validation Type | 설명 |
| --- | --- |
| Count Validation | Source / Target 데이터 건수 비교 |
| Sum Validation | 지정 컬럼 합계 비교 |
| Group By Validation | 그룹별 집계 결과 비교 |
| Row Compare Validation | Primary Key 기준 데이터 변경(INSERT / UPDATE / DELETE) 비교 |

---

## 5.1 Validator Class

### 클래스 정보

| Class | 역할 |
| --- | --- |
| Validator | Validation 유형별 검증 로직을 수행하는 핵심 클래스 |

### Method

| Method | 역할 |
| --- | --- |
| `_split_columns()` | Config 문자열(Column 목록)을 List 형태로 변환 |
| `validate_count()` | Source / Target Row Count 비교 |
| `validate_sum()` | 비교 대상 컬럼의 합계 비교 |
| `validate_groupby()` | Group By 집계 결과 비교 |
| `validate_rowcompare()` | Primary Key 기준 데이터 비교 및 INSERT / UPDATE / DELETE 검출 |

---

## 5.2 Validation 기능

| 기능 | 설명 | 결과 |
| --- | --- | --- |
| Count Validation | Source와 Target의 전체 데이터 건수를 비교 | PASS / FAIL |
| Sum Validation | 지정된 컬럼별 합계를 비교 | PASS / FAIL |
| Group By Validation | 그룹별 집계 결과를 비교하여 차이 데이터를 확인 | PASS / FAIL |
| Row Compare Validation | Primary Key 기준으로 INSERT, UPDATE, DELETE 데이터를 비교 | PASS / FAIL |




# 6. 데이터베이스 명세

## 6.1 ODS_SALES

**테이블명**

`valid.ods_sales`

**설명**

Source 시스템의 판매 데이터를 저장하는 테이블로 Validation의 기준(Source) 데이터로 사용한다.

| 컬럼명 | 타입 | PK | NOT NULL | 설명 |
| --- | --- | --- | --- | --- |
| sale_id | INTEGER | O | O | 판매번호 |
| sale_dt | DATE |  | O | 판매일자 |
| store_cd | VARCHAR(20) |  | O | 매장코드 |
| product_cd | VARCHAR(20) |  | O | 상품코드 |
| qty | INTEGER |  | O | 판매수량 |
| sale_amt | NUMERIC(10,2) |  | O | 판매금액 |



## 6.2 FACT_SALES

**테이블명**

`valid.fact_sales`

**설명**

DW 적재 결과를 저장하는 테이블로 Validation의 대상(Target) 데이터로 사용한다.

| 컬럼명 | 타입 | PK | NOT NULL | 설명 |
| --- | --- | --- | --- | --- |
| sale_id | INTEGER | O | O | 판매번호 |
| sale_dt | DATE |  | O | 판매일자 |
| store_cd | VARCHAR(20) |  | O | 매장코드 |
| product_cd | VARCHAR(20) |  | O | 상품코드 |
| qty | INTEGER |  | O | 판매수량 |
| sale_amt | NUMERIC(10,2) |  | O | 판매금액 |



## 6.3 VALIDATION_HISTORY

**테이블명**

`valid.validation_history`

**설명**

Validation 수행 결과를 저장하는 이력 테이블이다.

| 컬럼명 | 타입 | PK | NOT NULL | 설명 |
| --- | --- | --- | --- | --- |
| history_id | SERIAL | O | O | 이력번호 |
| validation_name | VARCHAR(100) |  | O | Validation 명 |
| count_result | VARCHAR(10) |  | O | Count Validation 결과 |
| sum_result | VARCHAR(10) |  | O | Sum Validation 결과 |
| groupby_result | VARCHAR(10) |  | O | Group By Validation 결과 |
| rowcompare_result | VARCHAR(10) |  | O | Row Compare Validation 결과 |
| run_dt | TIMESTAMP |  | O | Validation 수행 일시 |



### 테이블 관계

| Source Table | Target Table | Validation 대상 |
| --- | --- | --- |
| valid.ods_sales | valid.fact_sales | Count, Sum, Group By, Row Compare |
